On AArch64, 64-bit integer multiplication and the 64-bit integer Reduce_Add_Wrap, Reduce_Min, and Reduce_Max operations use scalar composition. On SSE2, 32- and 64-bit saturating arithmetic and all integer reduction operations use scalar composition. The SSE2 backend also uses scalar composition for floating Min_Number, Max_Number, Reduce_Add, Reduce_Min_Number, and Reduce_Max_Number.

The x86-64 backend uses scalar composition for Widen_Low, Widen_High, Narrow_Truncate, and Narrow_Saturate. Bit_Cast uses the same Ada implementation in both target backends. This fact does not make the private vector representation portable. The code-generation script lists the instruction classes that have positive checks.

Compiler scope

The executed compiler evidence uses GNAT FSF 16.1.0. GCC-based GNAT is the initial required compiler family.

GNAT LLVM remains a compatibility target. It is not an implemented or tested backend in this release.

Continuous checks

The workflow runs checked and release builds. Semantic checks include deterministic differential tests, independent lane oracles, full-width pseudorandom integer data, and floating-point edge cases.

The conversion tests cover integer truncation and saturation boundaries. Same-width signed/unsigned cases cover negative signed inputs around zero and unsigned inputs around the signed maximum. They also use deterministic, full-width pseudorandom inputs for the supported 8-, 16-, 32-, and 64-bit lanes. The tests cover F32 widening for signed zeros, subnormal and normal boundaries, infinities, and NaNs. Binary64 narrowing cases cover positive and negative halfway values, maximum finite binary32 values, overflow, gradual underflow to binary32 subnormals, underflow to signed zero, infinities, and NaNs. Integer-to-floating cases use an independent bit-level rounding oracle with deterministic, full-width pseudorandom inputs. Floating-to-integer cases use a separate bit-level oracle and raw pseudorandom floating encodings.

Memory checks include every tail length, protected pages, and AddressSanitizer. Code-generation checks inspect primitive operations and representative buffer loops.

Mask patterns and first/last true-lane results are exhaustive for each mask width. Byte-table tests cover every unsigned byte index, a fixed mapping of in-range and out-of-range indexes, and deterministic pseudorandom tables and indexes. Floating reduction cases include NaNs, infinities, and signed zero. The protected-page test runs all byte-tail counts from 0 through 16. AVX2 jobs require executable AVX2 coverage and do not silently skip it.

The workflow does not use continue-on-error.

Current limits

  • The public API is experimental.
  • The verified compiler matrix contains one GNAT FSF version.
  • The 256-bit family is not implemented.
  • General lane-index shuffles, lane slides, and compression are not implemented.
  • AVX2 accelerates three whole-buffer byte algorithms, not the primitive vector family.
