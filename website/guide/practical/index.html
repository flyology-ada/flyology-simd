Chapter 1 counted three commas in the first 16 bytes. The complete input has 26 bytes and four commas. One more iteration must process the final ten bytes.

Build and run the maintained example

If you do not have a source checkout, clone the repository:

git clone https://github.com/flyology-ada/flyology-simd.git
cd flyology-simd

From the checkout root, build and run the example:

alr exec -- gprbuild -p -P examples/examples.gpr
./bin/count_byte

The program prints 4 for all five count implementations. Its final backend name depends on the build and host.

Keep the ordinary loop as the result baseline

Byte_Array stores the input. Its U8 elements hold the byte values.

function Ordinary_Count
  (Source : Byte_Array;
   Needle : U8) return Natural
is
   Result : Natural := 0;
begin
   for Value of Source loop
      if Value = Needle then
         Result := Result + 1;
      end if;
   end loop;
   return Result;
end Ordinary_Count;

This function defines the application-level result: return the number of elements equal to Needle.

Advance by the number of loaded lanes

The tutorial function calls Backends.Native directly. The build selects its scalar, AArch64, or x86-64 body.

Each iteration loads a U8x16 and produces a Mask_8x16. Splat constructs the comma vector once before the loop.

function Explicit_Count_Commas (Source : Byte_Array) return Natural is
   Start  : Natural := Source'First;
   Result : Natural := 0;
   Wanted : constant U8x16 := Native.Splat (Comma);
begin
   while Start <= Source'Last loop
      declare
         Remaining : constant Natural := Source'Last - Start + 1;
         Count : constant Lane_Count_8x16 :=
           Lane_Count_8x16'Min (16, Remaining);
         Values : constant U8x16 :=
           Native.Load_Partial (Source, Start, Count);
         Matches : constant Mask_8x16 := Native.Equal (Values, Wanted);
      begin
         Result := Result + Native.Population_Count (Matches);
         Start := Start + Count;
      end;
   end loop;
   return Result;
end Explicit_Count_Commas;

A Lane_Count_8x16 value is in the range 0 through 16. Count is 16 in the first iteration and 10 in the second.

The native Load_Partial reads exactly Count bytes. Equal produces one truth value per lane. Population_Count adds the true lanes to the result.

Account for the zero-filled tail lanes

Load_Partial fills unused lanes with zero. This tutorial function counts commas, and the comma byte is not zero. The unused lanes therefore compare false.

Do not generalize this tail without preserving the condition.

To count byte value zero, mask out unused lanes or use a scalar tail. The maintained general-purpose Algorithms.*.Count implementations use full vector blocks followed by a scalar tail.

Chapter 3 gives the exact memory extent for a partial load and shows the boundary tests.

Check the complete result before changing composition

The ordinary and explicit loops both return 4. The scalar reference, static native, and runtime-dispatched algorithms return the same value:

ordinary source loop: 4
explicit U8x16 loop: 4
scalar reference backend: 4
static native algorithm: 4
runtime-dispatched algorithm: 4
