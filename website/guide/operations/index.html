Public vector and mask types

Each value vector is 128 bits. The type name gives the scalar type and lane count. For example, I32x4 contains four signed 32-bit lanes.

Lane typeValue typesMask type
8-bit integerU8x16, I8x16Mask_8x16
16-bit integerU16x8, I16x8Mask_16x8
32-bit integer or floatU32x4, I32x4, F32x4Mask_32x4
64-bit integer or floatU64x2, I64x2, F64x2Mask_64x2

Lane 0 is the first array element that a load reads. A compact mask uses bit 0 for lane 0. Bits above the mask lane count are ignored when you construct a mask.

Horizontal_Sum remains as a byte-specific convenience. It returns the exact sum as Natural. For U8x16, Reduce_Add_Wrap returns the sum modulo 256.

A logical shift returns zero in each lane when its count is equal to or greater than the lane width. An arithmetic right shift returns the sign fill for those counts.

The build does not enable -ffast-math. Ordered comparisons are false when either lane is NaN. Unordered is true for that case.

Min_Number and Max_Number return the numeric input when only one quiet NaN is present. They select negative zero for a minimum and positive zero for a maximum. The API reference and semantic document give the full NaN rules.

Combine and inspect masks

A mask is a Boolean value for each lane. It is not an integer vector. Use these operations instead of depending on its private representation:

  • Mask_And, Mask_Or, Mask_Xor, and Mask_Not combine lane truths.
  • Test reads one lane truth.
  • Any_True, All_True, and None_True reduce the mask to one Boolean.
  • Population_Count counts true lanes.
  • Mask_From_Bit_Mask constructs a mask from the low lane-count bits of a compact integer.
  • To_Bit_Mask returns a compact mask. Bit n represents lane n.
Printable : constant Mask_8x16 :=
  Mask_And
    (Greater_Equal (Bytes, Splat (16#20#)),
     Less_Equal (Bytes, Splat (16#7E#)));

if All_True (Printable) then
   --  All 16 bytes are printable ASCII.
end if;

Use typed arrays for memory operations

Each family has Load, Store, aligned variants, unaligned variants, and safe partial variants. Full operations require one complete vector of valid elements.

Has_Extent is a byte-family helper. It reports whether Count byte elements fit from Start. Is_Aligned_16 reports whether that byte element address is 16-byte aligned.

A partial load reads exactly Count elements and fills the remaining lanes with zero. A partial store writes exactly Count elements. A count of zero touches no element.

Reverse_Bytes is the byte-specific compatibility name for Reverse_Lanes. Horizontal_Sum is the byte-specific exact-sum convenience operation.

See the memory guide for a complete tail loop.

Not implemented in 0.1.0-dev

The following groups are design targets, not current API:

  • numeric Convert operations;
  • Bit_Cast operations;
  • widening and narrowing operations;
  • arbitrary lane-index shuffles, byte-table lookup, lane slides, and compression;
  • 256-bit vector and mask types;
  • first-true and last-true mask queries;
  • floating-point minimum and maximum reductions.
Coverage statement

“Full family” means that all ten 128-bit value types exist. It does not mean that every operation planned for the project exists.
